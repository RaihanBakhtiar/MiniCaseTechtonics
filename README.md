# BUSINESS-CASE-TECHTONIC

Working workspace for MCC Techtonic 3.0 x Terang.AI. This folder contains editable working documents; keep the official competition PDFs in their existing location and cite them in research notes.

## Start here

1. Read `01_CONTEXT/Competition-Brief.md` together as a team.
2. Run the 60-minute kick-off using `00_ADMIN/Kickoff-Worksheet.md`.
3. Assign and begin the critical tasks in `00_ADMIN/Task-Tracker.md`.
4. Follow `00_ADMIN/AI-Workflow-SOP.md`; one person owns final integration.

## Folder map

| Folder | Use |
|---|---|
| `00_ADMIN` | team agreements, tracker, AI workflow |
| `01_CONTEXT` | source-of-truth competition context and AI role prompts |
| `02_RESEARCH` | research log, sources, market and competitor analysis |
| `03_STRATEGY` | positioning, GTM, funnel and product strategy |
| `04_FINANCIALS` | financial assumptions, budget, unit economics and projections |
| `05_ROADMAP_KPIS` | implementation plan, milestones, KPI and risks |
| `06_DECK` | outline, slide assets and final export |
| `07_SOURCES` | downloaded/public source files and citation notes; do not duplicate official PDFs unnecessarily |
| `99_ARCHIVE` | dated snapshots and superseded drafts |

## File rules

- Keep claims, numbers, and assumptions traceable: add a URL/file reference and access date in `02_RESEARCH/Research-Log.md`.
- Mark any non-validated estimate as **ASSUMPTION** and record its owner.
- Name saved versions `YYYY-MM-DD_topic_v01`; never overwrite a submitted deck.
- The final deck must be English, 16:9, PDF, and at most 10 content pages excluding cover and appendix.
